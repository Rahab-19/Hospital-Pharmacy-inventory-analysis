
# Hospital Pharmacy Inventory Analysis

## 1. Project Overview
This project analyses synthetic hospital pharmacy
inventory data using Oracle SQL and Power BI.

## 2. Business Problem
Pharmacy inventory teams need accurate information
to monitor stock availability, identify products
requiring replenishment, monitor expiry dates and
understand medicine usage patterns.

## 3. Project Objectives
- Identify medicines below their reorder levels.
- Identify batches approaching expiry.
- Calculate inventory value by medicine category.
- Analyse medicine usage trends.
- Perform data quality checks.
- Present findings through a Power BI dashboard.

## 4. Tools
- Oracle SQL
- Power BI Desktop
- VS Code
- GitHub

## 5. Dataset
The project uses fictional medicine details,
inventory batches and usage transactions.
No real patient or hospital records are used.

## 6. Deliverables
- Oracle SQL scripts
- Data quality checks
- Inventory analysis
- Power BI dashboard
- Business findings and recommendations
